Reflection

This assignment was definitely on the easier side for me, while it was confusing at times figuring out where the directions are, what order to read them, and what exactly they’re asking; after the first few, I got the hang of it and everything else went by pretty smoothly. The only thing I’d say I had an issue with was that I forgot to add the tag at the very end, so originally my reflection was a column, and I was a bit confused at first, but after going through the code again, I was able to fix it easily. Honestly, I can see how helpful flexbox can be, but I also feel like if I were to try on my own, I’d make so many more mistakes and would have to troubleshoot a lot more. I don’t think I’d use it that much; however, I was thinking about using columns on my entry point page, so I’ll likely use flexbox there, hopefully it won’t be too hard doing it completely from scratch especially since I have this page to go off of. I was also debating on whether to keep the basic color palette or to change it to the one I’ve been going for. I ultimately decided to change it to mine since I have two pages already not matching, and I kept that since colors were part of the instructions, but for this one I figured it’d be best to maintain the theme.
