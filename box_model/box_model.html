Reflection

This assignment was definitely very colorful. I did have some confusion about following the directions, but once I understood, I was able to get through everything pretty quickly. I did change most of the colors (besides black and white) just so everything isn’t so bright and hard to read or see. However, I did keep my link color the same as my other pages (sans Mid-Century Blog) to keep consistency, especially since links are functional factors, and I feel like if I constantly change the color or orientation, it can lead to confusion among users. I think I will definitely visit this page a lot as a reminder of what I can do to customize each page and what the specific lines of code are for them, as I know I definitely will not be able to keep track of all the different kinds of code. There wasn’t as many errors as past assignments luckily, with maybe 2-4 small errors that I was very easily able to find the root cause for and fix it quickly. I think when applying these practices to my other pages, I’ll definitely play with padding a lot more. I think when I have time, I’ll copy the h1 CSS code into my h1 for my Point of Entry page and probably my other main pages as well (About and Inspiration).
