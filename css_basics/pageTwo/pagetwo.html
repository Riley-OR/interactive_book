Reflections

Since I have already been using CSS for a good amount of the assignments, the lesson was pretty straightforward for me, although there were a few tags I had forgotten how to use or the wording of, so it was nice to get a refresher on those. Even if I could connect all of my pages to one style sheet, I think at least for now, I’ll keep them all individual; it makes me feel better that, if I were to mess up a line of code, only one page will get messed up instead of the entire page, and I’d only be scrambling to fix one page and not the entire thing. For pages with grandchildren, I can definitely see myself connecting the CSS page to the child page if needed. There were definitely a few times when the links broke, and I had to troubleshoot them a few times before they finally worked, especially when linking the two pages together. I think I just have to continuously remind myself to rename everything if I need to, for it to be easier for me to understand, and to keep the names simple to read and to spell.
