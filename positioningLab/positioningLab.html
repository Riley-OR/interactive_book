positioning elements

Static

default, as-is behavior

Relative

this positions a child relative to its parent. by giving an element a relative position, we can place it outside the normal flow of where it would be- but it still impacts other elements

Absolute

this takes the element out of the line up and no longer impacts elements around it, BUT you have to apply position:relative to a parent container

Fixed

positioned in relation to the browser window, it just stays put!

***Sticky***

this one is a little more advanced, and we won’t get into it yet, but perhaps challenge yourself and your project to see if you can figure it out?


Next up: z-index

this is how we control layering when we are using positioning. if an element has a position, you can add a z-index, the larger the number the closer to the top.
0=bottom 100=top
think of z-index like the “bring to front” or “send to back” in design software.

Reflection

For this lesson, it felt easy doing it in class, but looking at it on my own, I can see how I can easily mess up or confuse certain tags. I still don’t have full confidence in the display tags, and adding a bit more complexity to them doesn’t ease me all that much. My only issue during the lab is that I can’t seem to get the dots on the right to move up. I tried messing with some of the CSS code; I don’t know if I just didn’t experiment with the right one or if I needed to add a whole other code altogether. On the other hand, z-index was very straightforward to me; I mean, essentially, it’s just numbering layers, with the highest being on top. As of now, I don’t have any layering ideas for my overall website, but I’ll definitely keep it in mind just in case, although I can see it getting very complicated very fast if there are too many elements being affected by the layers. Overall, I think the positioning we learned can be useful if I want a border-like effect on any of my pages; my main concern would be that it can make the site look too busy and too extreme, so I’d definitely have to use it with caution.
